A one-line office joke, delivered as a calendar notification — the driest artifact in office life. The program writes the single line to `entry.txt` in the output directory, exactly as the judge reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
